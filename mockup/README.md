# モックアップ（RaiseTechtimeline）

要件定義書・機能定義書（`../docs/`）をもとに、HTML・CSS・JavaScript だけで作った動くモックアップ。本番のアプリでは使わない（画面と動きの確認用）。

## 開き方

`mockup/index.html` をブラウザ（Chrome・Edge など）で開く。サーバーはいらない。

- ログイン画面の「入力する」で、デモのアカウント（demo@example.com ／ password123）が入る
- 新規登録もできる

## できること

| 画面 | 試せること |
|---|---|
| S-01 ログイン・S-02 新規登録 | 入力チェックとエラーの文言、登録したら自動でログイン |
| S-03 タイムライン | 「すべて」「フォロー中」タブ、20件ずつのスクロール読み込み、280文字の残り文字数、画像4枚まで／動画1本の添付 |
| S-04 投稿詳細 | コメント・返信（何段でも。表示は1段の字下げ）、コメントへのいいね、コメントした人のフォロー |
| S-05 プロフィール | フォロー・フォローバック・「フォローされています」、フォロー数・フォロワー数 |
| S-06 プロフィール編集 | 表示名・自己紹介・アイコン画像 |
| S-07 フォロー・フォロワー一覧 | タブの切り替え、一覧からのフォロー |
| S-08 ユーザー検索 | 部分一致、全角・半角と大文字・小文字の違いを無視 |
| M-01〜M-03 | 投稿・編集のモーダル、いいねしたユーザー、削除などの確認 |

## 注意

- データはブラウザのメモリに持つだけ。**再読み込みすると最初の状態に戻る**
- 画像・動画は選んだファイルをその場で表示するだけで、どこにも送らない（本番は S3）。動画の「送信中」の表示も見た目だけ
- 画面の幅：パソコン（1024px 以上）、タブレット（768〜1023px）、スマホ（767px 以下）で並び方が変わる

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の土台 |
| `style.css` | 見た目（色の決まりは先頭の `:root`） |
| `data.js` | サンプルのユーザー・投稿・コメントなど |
| `app.js` | 画面の切り替えと動き |
