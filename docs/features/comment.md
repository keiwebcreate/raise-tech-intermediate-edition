# 機能定義書：コメント（返信を含む）

| 項目 | 内容 |
|---|---|
| 対象の機能 | C-01〜C-05（[機能一覧](../features.md) 1.4）。コメントへのいいねは [like.md](like.md)（L-04） |
| 版 | 0.2（2026-11-08） |

## 1. 概要

投稿にコメントを付ける。自分の投稿にも、**他の人の投稿にも**コメントできる。X と同じく、**コメントにも返信**でき、返信にもさらに返信できる。コメントの一覧からは、コメントした人をフォローできる。

| 用語 | 意味 |
|---|---|
| コメント | 投稿に直接付けたもの |
| 返信 | コメント（または返信）に付けたもの。中身の決まりはコメントと同じ |

## 2. 誰が使えるか

| 機能 | 使える人 |
|---|---|
| コメント・返信をする・一覧を見る | ログインしている人 |
| コメント・返信の削除 | **書いた本人だけ**。サーバーでも本人かを確かめ、他人のものは 404 |

## 3. 入力と制限

| 項目 | 必須 | ルール |
|---|---|---|
| 本文 | ○ | 1〜280文字（投稿と同じ。数え方も [post.md](post.md) 3.1 と同じ）。空白だけは不可。改行は使える |

- 画像は付けられない
- 返信の深さに上限はない（返信の返信の返信…もできる）。表示の仕方は 4.2
- コメント・返信にもいいねできる（[like.md](like.md) 4.4）
- コメントの編集はない（打ち間違えたら消して書き直す）

## 4. 処理の流れ

### 4.1 コメントする（C-01）

1. 投稿の詳細（S-04）の入力欄に本文を入れ、「コメントする」を押す
2. サーバーは入力をチェックし、投稿があるかを確かめてから `comments` に保存する
3. 画面はコメントの一覧の一番下に足し、投稿のコメント数を1つ増やす。入力欄は空にする

### 4.2 コメントの一覧と返信の表示（C-02）

- 投稿の詳細に、投稿への**コメントを古い順**（会話の順）に表示する。50件ずつ「さらに表示」で読み込む
- 返信は、元になったコメントの下に**1段だけ字下げ**して、古い順に並べる
  - 最初は返信を出さず、「返信を表示（3件）」を押すと開く
  - 返信への返信も、同じ段にまとめて並べ、本文の上に「返信先：@ユーザー名」と出す（段を深くしすぎると、スマホで読めなくなるため）
- 1件に出すもの：アイコン・表示名・@ユーザー名・日時・（返信なら）返信先・本文・返信ボタンと返信数・いいね（ハートと数）・フォローボタン・（自分のものなら）削除
- **フォローボタン**（[profile.md](profile.md) 4.3 と同じ部品）：自分のコメントには出さない

### 4.3 コメント数・返信数（C-03）

| 数 | 出す場所 | 数えるもの |
|---|---|---|
| コメント数 | 投稿（タイムライン・投稿の詳細・プロフィール） | 投稿に直接付いたコメントだけ（X と同じ。返信は含めない） |
| 返信数 | コメント・返信 | そのコメントに直接付いた返信だけ |

### 4.4 削除（C-04）

1. 自分のコメントの「削除」で、確認のダイアログ（M-03）を出す
   - 返信がないとき：「このコメントを削除しますか？」
   - 返信があるとき：「このコメントを削除しますか？ このコメントへの返信も消えます」
2. 「削除する」で、そのコメントと、その下に付いた返信をすべて消す（いいねも一緒に消える）。数を減らす

### 4.5 返信する（C-05）

1. コメント・返信の「返信」ボタンを押すと、そのすぐ下に入力欄を開く。入力欄の上に「返信先：@ユーザー名」と出す
2. 本文を入れて「返信する」を押す
3. サーバーは、返信先のコメントがあり、**同じ投稿のもの**かを確かめてから、返信先を記録して `comments` に保存する
4. 画面は返信の並びの一番下に足し、返信先の返信数を1つ増やす（返信が閉じていたら開く）
5. Esc か「キャンセル」で入力欄を閉じる。入力していたら「編集内容を破棄しますか？」と確かめる

## 5. エラーのとき

| 場面 | 表示する文言 |
|---|---|
| 本文が空 | 「コメントを入力してください」（ボタンを押せなくしておく） |
| 280文字を超えた | 「280文字以内で入力してください」 |
| 投稿が消されていた | 「この投稿は見つかりません」 |
| 返信先のコメントが消されていた | 「返信先のコメントは削除されました」 |
| 送信の失敗 | 「コメントに失敗しました。時間をおいて再度お試しください」（入力した内容は消さない） |

## 6. 関係する画面・テーブル

- 画面：S-04 投稿詳細、M-02 いいねしたユーザー、M-03 確認ダイアログ（[screen-design.md](../screen-design.md)）
- テーブル：`comments`（返信先は `parent_comment_id`）・`comment_likes`・`users`・`follows`（フォローボタンの状態）

## 7. この文書で新しく決めたこと（確認をお願いします）

- コメントは古い順（会話として読みやすいため）。50件ずつ
- 返信は X と同じく何段でもできるが、表示は1段の字下げにまとめ、「返信先：@ユーザー名」で相手を示す
- 返信は最初は閉じておき、「返信を表示（○件）」で開く
- 投稿のコメント数は、直接のコメントだけを数える（X と同じ）
- コメントを消すと、その下の返信も一緒に消える（X は返信を残すが、作りが複雑になるため）
- コメントの編集はない。投稿の持ち主でも、他人が付けたコメントは消せない
