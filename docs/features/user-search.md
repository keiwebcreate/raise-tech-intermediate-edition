# 機能定義書：ユーザー検索（フォローする人の探し方）

| 項目 | 内容 |
|---|---|
| 対象の機能 | US-01・US-02（[機能一覧](../features.md) 1.8） |
| 版 | 0.1（2026-11-08） |

## 1. 概要

フォローしたい人を見つけるための機能。講義の「ユーザーをどうやって検索するかも詰めておきたい」に対して、次の **4つの入口** を用意する（ユーザーと決めた）。

| 入口 | 場所 | 詳しくは |
|---|---|---|
| ① ユーザー検索 | 検索画面（S-08）で名前の一部を入れる | この文書 |
| ② コメントの一覧 | 投稿の詳細（S-04）の、コメントした人の横のフォローボタン | [comment.md](comment.md) 4.2 |
| ③ いいねした人の一覧 | 投稿のいいね数を押して開く一覧（M-02）のフォローボタン | [like.md](like.md) 4.3 |
| ④ プロフィールへの移動 | 投稿・コメント・一覧のアイコンや名前を押す → プロフィールのフォローボタン | この文書 4.2 |

フォローボタンは、どこでも同じ部品（[profile.md](profile.md) 4.3）。

## 2. 誰が使えるか

ログインしている人。

## 3. 入力と制限（US-01）

| 項目 | ルール |
|---|---|
| 検索の言葉 | 1〜50文字。前後の空白は取り除く。先頭の `@` は無視する（`@taro` でも `taro` でも同じ） |
| 探す対象 | **ユーザー名**と**表示名**の、どちらかに言葉を**含む**ユーザー（部分一致） |
| 文字の違い | 大文字・小文字、全角・半角は同じとみなす（「ＴＡＲＯ」でも「taro」が見つかる） |
| 自分 | 結果に出してよい（フォローボタンは出さない） |
| 並び順 | ① ユーザー名が言葉と完全に同じ人 → ② ユーザー名・表示名が言葉で始まる人 → ③ それ以外。同じ順位の中はフォロワーの多い順 |
| 件数 | 20件ずつ（スクロールで続き） |

## 4. 処理の流れ

### 4.1 ユーザー検索（US-01）

1. 画面の左のメニュー（スマホは下のメニュー）の「検索」で、検索画面（S-08）を開く
2. 検索欄に言葉を入れる。入力が止まって0.3秒たったら検索する（Enter でも検索。日本語の変換中は検索しない）
3. 結果を一覧で出す。1件に出すもの：アイコン・表示名・@ユーザー名・「フォローされています」・自己紹介（1行まで）・フォローボタン
4. 名前やアイコンを押すと、その人のプロフィールへ
5. 検索の言葉は URL に入れる（`/search?q=taro`）。戻る・再読み込みでも同じ結果

### 4.2 プロフィールへの移動（US-02）

- 投稿・コメント・ユーザーの一覧に出る**アイコン・表示名・@ユーザー名**は、すべてその人のプロフィール（`/users/{ユーザー名}`）へのリンクにする

## 5. 表示

| 場面 | 表示 |
|---|---|
| 入力する前 | 「ユーザー名や名前で検索できます」 |
| 見つからない | 「「○○」に一致するユーザーは見つかりませんでした」 |
| 検索の失敗 | 「検索に失敗しました」と「もう一度試す」ボタン |

## 6. 関係する画面・テーブル

- 画面：S-08 ユーザー検索、S-04 投稿詳細、M-02 いいねしたユーザー、S-05 プロフィール（[screen-design.md](../screen-design.md)）
- テーブル：`users`・`follows`

## 7. この文書で新しく決めたこと（確認をお願いします）

- 入力が止まったら自動で検索する（検索ボタンは置かない）
- 並び順：完全一致 → 前方一致 → 部分一致、同じ順位はフォロワーの多い順
- おすすめユーザー（「おすすめユーザー」の欄）は作らない
