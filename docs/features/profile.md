# 機能定義書：プロフィール・フォロー

| 項目 | 内容 |
|---|---|
| 対象の機能 | PF-01・PF-02、FL-01〜FL-04（[機能一覧](../features.md) 1.6・1.7） |
| 版 | 0.1（2026-11-08） |

## 1. 概要

ユーザーごとのプロフィールを表示・編集する。他のユーザーをフォローし、フォロー数・フォロワー数とその一覧を見られる。自分をフォローしている人は、すぐにフォローバックできる。

## 2. 誰が使えるか

| 機能 | 使える人 |
|---|---|
| プロフィール・一覧を見る | ログインしている人（誰のプロフィールでも） |
| プロフィールの編集 | 本人だけ |
| フォロー・解除 | ログインしている人。自分自身はフォローできない |

## 3. プロフィール

### 3.1 表示（PF-01）

URL は `/users/{ユーザー名}`。

| 項目 | 内容 |
|---|---|
| アイコン | 未設定なら初期のアイコン |
| 表示名・@ユーザー名 | |
| フォローされています | 相手が自分をフォローしているときだけ、ユーザー名の横に小さく出す |
| 自己紹介 | 改行をそのまま表示 |
| 登録した月 | 「2026年11月から利用しています」 |
| フォロー数・フォロワー数 | 「12 フォロー」「34 フォロワー」。押すと一覧（S-07） |
| ボタン | 自分：「プロフィールを編集」。他人：フォローボタン（4.3） |
| 投稿の一覧 | その人の投稿を新しい順に20件ずつ（表示はタイムラインと同じ） |

ないユーザー名なら「このアカウントは存在しません」。

### 3.2 編集（PF-02）

| 項目 | 必須 | ルール |
|---|---|---|
| 表示名 | ○ | 1〜50文字。前後の空白は取り除く |
| 自己紹介 | | 160文字まで。改行は使える |
| アイコン画像 | | JPEG・PNG・WebP。5MB まで。正方形に切り取り、400×400px に縮小して S3 に保存する。「画像を外す」で初期のアイコンに戻せる |

- ユーザー名とメールアドレスは、ここでは変えられない（[authentication.md](authentication.md) 7）
- 「保存する」で保存し、プロフィールへ戻って「プロフィールを更新しました」と出す
- アイコンを差し替え・外したら、前の画像は S3 からも消す
- 保存せずに離れるときは「編集内容を破棄しますか？」と確かめる

## 4. フォロー

### 4.1 フォロー・解除（FL-01）

1. フォローボタンを押すと、すぐに表示を変える（いいねと同じ。失敗したら戻す）
2. サーバーで `follows` に「誰が（follower）誰を（following）」を足す。解除は消す
   - 自分自身は不可（サーバーでも断る）
   - 2回目のフォローはエラーにせず「フォロー済み」として扱う
3. 解除は、ボタンを押したら「@ユーザー名 さんのフォローを解除しますか？」と確かめてから行う

### 4.2 フォローバック（FL-02）

- 相手が自分をフォローしていて、自分は相手をフォローしていないとき、ボタンの文字を「**フォローバック**」にする
- 押したときの動きは、ふつうのフォローと同じ

### 4.3 フォローボタン（共通の部品）

ユーザーが並ぶところ（プロフィール・フォロー/フォロワーの一覧・検索結果・コメント・いいねした人の一覧）では、すべて同じ部品を使う。

| 状態 | ボタンの文字 | 見た目 |
|---|---|---|
| フォローしていない | フォローする | 塗りつぶし |
| 相手だけが自分をフォローしている | フォローバック | 塗りつぶし |
| フォロー中 | フォロー中（マウスを乗せると「フォロー解除」） | 枠だけ |
| 自分 | （出さない） | |

### 4.4 フォロー数・フォロワー数（FL-03）

- プロフィールに出す。数は毎回 `follows` から数える

### 4.5 フォロー・フォロワーの一覧（FL-04）

- URL は `/users/{ユーザー名}/following`（フォロー中）と `/users/{ユーザー名}/followers`（フォロワー）。2つのタブで切り替える
- 新しくフォローした順に20件ずつ（スクロールで続き）
- 1件に出すもの：アイコン・表示名・@ユーザー名・「フォローされています」・自己紹介（1行まで）・フォローボタン
- 空のとき：「まだ誰もフォローしていません」「まだフォロワーはいません」

## 5. エラーのとき

| 場面 | 表示する文言 |
|---|---|
| 表示名が空 | 「表示名を入力してください」 |
| 自己紹介が160文字を超えた | 「自己紹介は160文字以内で入力してください」 |
| アイコンの種類・大きさ | 「JPEG・PNG・WebP の画像を選んでください」「画像は5MBまでです」 |
| フォロー・解除の失敗 | 表示を元に戻し、「フォローに失敗しました」 |
| ないユーザー | 「このアカウントは存在しません」 |

## 6. 関係する画面・テーブル

- 画面：S-05 プロフィール、S-06 プロフィール編集、S-07 フォロー・フォロワー一覧、M-03 確認ダイアログ（[screen-design.md](../screen-design.md)）
- テーブル：`users`・`follows`・`posts`。アイコンは S3

## 7. この文書で新しく決めたこと（確認をお願いします）

- プロフィールの項目：表示名（50文字）・自己紹介（160文字）・アイコン。ヘッダー画像・場所・Web サイトは作らない
- 「フォローされています」の表示と、「フォローバック」のボタン
- フォロー解除の前に確認を出す（押し間違いを防ぐ）
- 一覧は新しくフォローした順
