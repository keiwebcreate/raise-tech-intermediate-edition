# 機能定義書：タイムライン

| 項目 | 内容 |
|---|---|
| 対象の機能 | TL-01〜TL-04（[機能一覧](../features.md) 1.2） |
| 版 | 0.1（2026-11-08） |

## 1. 概要

投稿を新しい順に並べて表示する、アプリのメインの画面。2つのタブを切り替えて使う。

| タブ | 出す投稿 |
|---|---|
| すべて（TL-01） | フォローしていない人も含め、**全員の投稿** |
| フォロー中（TL-02） | **自分**と、**自分がフォローしている人**の投稿 |

## 2. 誰が使えるか

ログインしている人。

## 3. 表示のルール

| 項目 | ルール |
|---|---|
| 並び順 | 投稿した日時の新しい順（編集しても順番は変わらない） |
| 最初に開くタブ | 前回見ていたタブ（ブラウザに覚えておく）。はじめてのときは「すべて」 |
| 1回に読む件数 | 20件。下までスクロールしたら、次の20件を読み込む（TL-03） |
| 新しい投稿 | 自分が投稿したら、一覧の一番上に足す。他の人の新しい投稿は、タブを押し直すか再読み込みで出る（自動では出ない） |
| 空のとき | すべて：「まだ投稿がありません」。フォロー中：「まだ誰もフォローしていません。『すべて』や検索から、気になる人を探してみましょう」と、検索画面へのリンク |

### 3.1 投稿1件の表示内容（TL-04）

| 項目 | 内容 |
|---|---|
| アイコン | 未設定なら初期のアイコン。押すとプロフィールへ |
| 表示名・@ユーザー名 | 押すとプロフィールへ |
| 投稿日時 | 「3分前」「2時間前」「11月8日」「2025年12月1日」のように表示（要件 N-06）。マウスを乗せると正確な日時 |
| 編集済み | 編集した投稿にだけ「編集済み」 |
| 本文 | 改行をそのまま表示する |
| 画像・動画 | あれば表示。画像は4枚までを並べ、押すと大きく表示。動画は再生ボタン付き（並べ方は [post.md](post.md) 4.2） |
| コメント数 | 吹き出しのアイコン＋数。押すと投稿の詳細へ |
| いいね数 | ハートのアイコン＋数。ハートを押すといいね、数を押すといいねした人の一覧（[like.md](like.md)） |
| 「…」メニュー | 自分の投稿にだけ出す。「編集」「削除」 |

本文やアイコン以外のところを押すと、投稿の詳細（S-04）を開く。

## 4. 処理の流れ

1. 画面がサーバーに「どちらのタブか」と「どこまで読んだか（最後の投稿）」を送る
2. サーバーは投稿を新しい順に20件と、それぞれのコメント数・いいね数・自分がいいねしたかを返す
   - 「フォロー中」は、`follows` で自分がフォローしている人と自分の投稿だけに絞る
   - 続きの読み込みは「最後に読んだ投稿より古いもの」で探す（途中で新しい投稿が増えても、同じ投稿が2回出たり抜けたりしないようにするため）
3. 画面は受け取った投稿を一覧の下に足す。20件より少なければ「これ以上はありません」として読み込みをやめる

## 5. エラーのとき

| 場面 | 表示 |
|---|---|
| 読み込みの失敗 | 「読み込みに失敗しました」と「もう一度読み込む」ボタン |

## 6. 関係する画面・テーブル

- 画面：S-03 タイムライン（[screen-design.md](../screen-design.md)）
- テーブル：`posts`・`users`・`follows`・`likes`・`comments`

## 7. この文書で新しく決めたこと（確認をお願いします）

- 「フォロー中」タブには自分の投稿も出す（X と同じ）
- 最初に開くタブは前回のタブ（はじめては「すべて」）
- 20件ずつ、スクロールで続きを読む。新しい投稿は自動では出ない（自動で出す仕組みは大がかりになるため）
